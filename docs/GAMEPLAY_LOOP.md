# Dead Circuit — Gameplay Loop

## Core Loop

```text
Start Run
    ↓
Enter Room
    ↓
Combat / Event / Reward
    ↓
Gain Resources or Build Power
    ↓
Choose Next Room
    ↓
Repeat
    ↓
Boss
    ↓
Floor Reward / Special Opportunity
    ↓
Next Floor
```

## Combat Loop

```text
Enter combat encounter
        ↓
Enemies spawn / pressure begins
        ↓
Player fights
        ↓
Build effects interact
        ↓
Encounter escalates
        ↓
Enemies cleared
        ↓
Reward / progression
```

## Run Progression

Players should progress through several overlapping systems:

- items
- weapons
- weapon evolution
- perks
- economy
- health/resources
- room routing
- special deals

These systems should create decisions rather than simply increasing every statistic simultaneously.

## Floor Progression

Early floors:

- fewer enemies
- simple room layouts
- forgiving boss mechanics
- limited elite combinations

Later floors:

- larger hordes
- more aggressive spawning
- additional elite types
- layered encounter mechanics
- dangerous boss interactions
- stronger build expectations

## Run Failure

Death ends the current run unless modified by a specific revive mechanic.

Run state must reset cleanly.

Future meta-progression must not be assumed by early systems.

## Replayability

Replayability should come from:

- procedural floor structure
- item combinations
- weapon choices
- encounter variation
- boss variation
- special paths
- risk/reward decisions
- seeded runs
