# Dead Circuit v0.0.3 — Seeded Runs

Authoritative seeded runs build on the accepted Combat Sandbox and Item / Synergy Proof.

## Included

- Authoritative run seed and isolated run RNG
- Reproducible zombie spawn-marker rolls
- Up to three distinct unowned item choices from seeded rolls
- Stable player/item ordering for authoritative selections
- Visible seed, validated seed input and same-seed Replay
- Clean seed, health, ammo, item and wave reset
- Existing first-person movement, sprint, pistol and reload
- Five zombie waves, item synergies, HUD, pause/resume and death/completion restart
- Windows and Linux builds

## Known Limitations

This is an early prototype.

- One primitive greybox arena and placeholder enemy visuals
- Basic AI, temporary balance and unpolished movement/weapon feel
- No production audio or final animations
- The same seed reproduces authoritative choices with the same content, player
  roster and item selections; physics, aiming and combat timing are not deterministic
- Encounter variation currently changes spawn placement, not enemy types
- No procedural rooms, bosses or multiplayer
