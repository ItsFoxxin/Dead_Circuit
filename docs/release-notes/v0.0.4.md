# Dead Circuit v0.0.4 — Room Framework

An authored room route extends the accepted combat, item and seeded-run foundation.

## Included

- Start, five-wave Combat, Treasure and Boss Staging rooms
- Green EXIT markers with E interaction and encounter locks
- Player health, ammunition, items and source ownership persist between rooms
- Treasure item choices for each living participant
- One authoritative run RNG across the full route
- Whole-run Replay after death or Room Framework completion
- Existing first-person movement, sprint, pistol, reload, items and pause/resume
- Windows and Linux builds

## Known Limitations

This is an early prototype.

- Authored linear route with reused greybox geometry; no procedural room graph
- Boss Staging is a placeholder; actual boss combat begins in v0.0.5
- Temporary movement/weapon feel, AI, balance and visuals; no production audio
- This version retains between-wave item choices; v0.0.5 changes reward pacing
- EXIT placement and angled label readability fixes are part of v0.0.5
- Same-seed authority choices are reproducible; physics, aiming and timing are not
- No multiplayer, progression or save profiles
