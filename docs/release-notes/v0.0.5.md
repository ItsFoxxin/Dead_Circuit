# Dead Circuit v0.0.5 — First Boss

The first complete prototype floor now ends with an actual boss fight, a second
item reward and a clear floor-complete state.

## Included

- Prototype Brute boss with pursuit and a visible, avoidable slam windup
- Source-aware boss damage, death and kill effects through the shared combat path
- One Treasure item and one boss reward per floor, with no between-wave upgrades
- Seeded chance for a small health or reserve-ammo supply after room clears
- Boss exit locked through defeat and each living participant's reward choice
- Whole-run completion, death and Replay reset without stale boss/reward state
- EXIT panels aligned to walls and room/EXIT labels facing the camera
- Existing movement, pistol, five items, five waves, seeded run and room route
- Windows and Linux builds

## Known Limitations

This is an early prototype.

- One primitive boss, one attack and no adds, phases or cinematic behavior
- One authored linear floor with temporary greybox rooms
- Five-item pool and one weapon; broader variety begins in later milestones
- Temporary movement/weapon feel, AI, balance, effects and visuals
- No production animation or audio
- Same-seed authority choices are reproducible; physics, aiming and timing are not
- No multiplayer, progression, save profiles or procedural room graph
